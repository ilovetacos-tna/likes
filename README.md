## Likes and Dislikes

This is inspired by kinksheet.com, and intended to provide a mechanism for TNA members (and others) to share links with activities they're interested in, then compare the answers to see what is common, thus avoiding much of the ambiguity of the current Likes/Dislikes.  Answers live only in the share links and in each person's browser's local storage. 

It's provided with love from ilovetacos.
